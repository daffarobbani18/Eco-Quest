# 🎯 TUTORIAL LENGKAP: SETUP & PERBAIKAN UNITY ECO-QUEST
## Panduan Step-by-Step untuk Developer

---

## 📚 DAFTAR TUTORIAL

Tutorial ini dibagi menjadi **5 TAHAP LENGKAP**:

### **TAHAP 1: Persiapan & Verifikasi Awal** ⏱️ 15 menit
- Backup project
- Cek struktur folder
- Verifikasi script yang sudah diperbaiki
- Persiapan testing

### **TAHAP 2: Setup Scene 02 (Kantin)** ⏱️ 30 menit
- Membuat/Verifikasi GameManager
- Setup CollectionLevelManager
- Membuat LevelData_Kantin
- Setup UI & Briefing
- Testing Scene 02

### **TAHAP 3: Update WasteData (Skor Dinamis)** ⏱️ 20 menit
- Membuat WasteData baru
- Update WasteData yang sudah ada
- Testing skor per sampah
- Balancing game

### **TAHAP 4: Setup Scene 03 (Processing)** ⏱️ 45 menit
- Membuat Hierarchy dari awal
- Setup ProcessingLevelManager
- Setup WasteSpawner
- Membuat LevelData_Processing
- Setup UI HUD & Panel Menang
- Konfigurasi Inspector lengkap

### **TAHAP 5: Testing & Debugging Final** ⏱️ 30 menit
- Test Scene 02 standalone
- Test Scene 03 standalone
- Test transisi Scene 02 → 03
- Troubleshooting umum
- Final verification

---

## 🎮 TOTAL WAKTU ESTIMASI: 2.5 Jam

**Rekomendasi:**
- Lakukan 1 tahap per sesi
- Jangan skip tahap
- Save project setelah setiap tahap selesai
- Test setelah setiap tahap

## ⚡ QUICK START

**Jika Anda sudah familiar dengan Unity:**
1. Baca TAHAP 1 untuk persiapan
2. Langsung ke TAHAP yang bermasalah
3. Lakukan testing di TAHAP 5

**Jika Anda pemula:**
1. Ikuti SEMUA tahap berurutan
2. Jangan skip langkah
3. Pause dan test setelah setiap tahap
